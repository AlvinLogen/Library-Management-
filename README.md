# Book Library Management System

## Why This Project?
Incorporates advanced T-SQL concepts with real-world complexity:
- **Complex relationships:** Books, Authors, Publishers, Categories (many-to-many)
- **Advanced queries:** Search, filtering, sorting, analytics
- **Window functions:** Rankings, running totals, analytics
- **CTEs:** Hierarchical categories, recursive queries
- **Performance:** Large dataset optimization (10,000+ books)

## Application Features
1. **Book Management:** CRUD operations with advanced search
2. **Author Management:** Multiple authors per book (many-to-many)
3. **Category Hierarchy:** Recursive categories with CTEs
4. **Advanced Analytics:** 
   - Most borrowed books
   - Author popularity rankings
   - Reading trends over time
   - Library statistics dashboard
5. **Search & Filtering:** Full-text search, multi-criteria filtering
6. **Performance Monitoring:** Query execution tracking
